# Bolsillos

App instalable (PWA) para llevar los gastos por quincena, el ritual del día de pago y el colchón.

- La página no guarda datos: cada celular se conecta a su propia hoja de Google con un código de conexión que se pega dentro de la app.
- Funciona sin señal: lo anotado queda en el celular y se envía a la hoja cuando vuelve la conexión.
- En iPhone: abrir el enlace en Safari → Compartir → Agregar a inicio.

Archivos: `index.html` (la app), `sw.js` (copia para usar sin señal), `manifest.webmanifest` e `icons/`.
